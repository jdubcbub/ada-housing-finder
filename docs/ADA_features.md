# Accessibility Features
Developer note: R&D on this collection should be ongoing.

## Exterior, Parking, & Building Access
| Feature | Description |
| --- | --- |
| **Ramp or Step-Free Entry** | Zero-step entrances or ramps with handrails into the building. |
| **Elevator** | Accessible elevator access for all multi-story layouts. |
| **Handicapped Parking** | Designated extra-wide or van-accessible parking stalls close to the entrance. |
| **Covered Drop-off Zone** | A canopy or portico with high clearance for accessible vans with lifts. |
| **Flat Sidewalks & Smooth Routes** | Continuous, step-free paved paths to mailboxes, trash chutes, the leasing office, and common areas. |
| **Automated Doors** | Push-button or sensor-activated main building doors. |
| **Accessible Common Areas** | Roll-in entries to community spaces, pool chair-lifts, and lowered machines in shared laundry rooms. |
| **Safe Evacuation Areas** | Fire-safe holding zones on upper floors near stairwells with built-in two-way emergency intercoms. |

## Inside the Space (General Layout)
| Feature | Description |
| --- | --- |
| **Single-Story Layout** | No stairs or steps anywhere inside the rental unit. |
| **Wide Doorways & Hallways** | Openings measuring at least 32 to 36 inches to clear wheelchairs and walkers. |
| **Open Floor Plan (Turning Radius)** | A clear, unobstructed 5-foot turning circle in main living areas. |
| **Hard Floors / Flat Thresholds** | Smooth hardwood, vinyl, or tile; low-pile carpet; and flat door thresholds (1/4 to 1/2 inch max with bevels). |
| **Lever Door Handles** | Flat lever handles instead of round doorknobs. |
| **Easy-Open Doors** | Lightweight interior and exterior doors that require minimal force to push or pull open. |
| **Lowered Switches & Raised Outlets** | Electrical outlets raised up and light switches lowered so they are easy to reach from a seated position. |
| **Accessible Windows** | Window latches and openings placed low enough to open with minimal physical force. |
| **Lowered Closet Rods** | Adjustable or lowered shelving and closet racks. |

## Kitchen Features
| Feature | Description |
| --- | --- |
| **Lowered Counters** | Shorter countertops (around 34 inches high) for comfortable sitting or reaching. |
| **Roll-Under Sink & Cooktop** | Open knee space beneath the sink or stove, featuring insulated pipes to prevent leg burns. |
| **Front-Control Appliances** | Knobs on the front of the stove/oven so you do not have to reach over hot burners. |
| **Pull-Out / Drop-Down Shelving** | Cabinets with pull-out drawers, pull-down tracks, or lazy Susans. |
| **Accessible Appliance Designs** | Side-by-side refrigerators, drawer-style microwaves, or drawer dishwashers. |

## Bathroom Features
| Feature | Description |
| --- | --- |
| **Roll-In Shower or Walk-In Tub** | A zero-step, curbless shower entry or a bathtub with a sealed walk-in door. |
| **Grab Bars** | Sturdy handrails securely installed next to the toilet and inside the shower/tub. |
| **Tall Toilet** | A higher, "comfort-height" toilet seat (17 to 19 inches high) to make transfers easier. |
| **Roll-Under Vanity** | Open knee space under the bathroom sink. |
| **Handheld Showerhead** | A detachable sprayer on a long, adjustable sliding hose. |

## Sight, Sound, & Sensory Features
| Feature | Description |
| --- | --- |
| **Flashing Alarms & Doorbells** | Strobe light alerts hardwired to smoke detectors and the front doorbell. |
| **Assistive System Plugs** | Outlets wired directly into the building's emergency matrix to support personal shake-awake bed vibrators. |
| **Braille & High-Contrast Signage** | Raised lettering and Braille on unit numbers, public signs, and control panels. |
| **Dimmable & Non-Glare Lighting** | Light fixtures that can be fine-tuned to prevent flickering or sensory overload. |
| **High-Contrast Trim** | Visual contrast strips marking countertop edges, steps, and floor transitions to prevent trips. |
| **Soundproofing / Acoustic Dampening** | Enhanced wall insulation or double-pane glass to minimize outside noise and sensory distress. |

## Administrative Accommodations
| Feature | Description |
| --- | --- |
| **Assigned Proximate Parking** | A policy guaranteeing a specific accessible parking space reserved exclusively for your unit number. |
| **Waived Assistance Animal Policies** | Written exemption from pet fees, security deposits, and weight/breed restrictions for documented Service Animals or Emotional Support Animals (ESAs). |
